# Captação de restaurantes

A página principal apresenta o relatório mensal e permite consultar um exemplo com dados fictícios em /restaurantes/. As duas ofertas de infraestrutura continuam acessíveis na secção Outros serviços Galzu. A página original conserva os detalhes e o diagnóstico de negócios locais.

O contacto para relatórios é feito por mensagem através dos perfis Instagram @galzugal e Facebook galzuservices. A integração de email fica para uma revisão posterior, após validar a entrega no destino indicado.
